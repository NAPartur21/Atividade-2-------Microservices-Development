# Pasta de entrega

Coloque aqui os dois arquivos que o enunciado pede (antes de subir para o GitHub):

1. `dashboard-grafana.png` - print screen do dashboard "Logins - MS-AV-02" com números reais (faça alguns logins válidos/inválidos e bloqueie um usuário antes do print).
2. `dashboard-exportado.json` - no Grafana: abra o dashboard > **Export** > **Export as code** > **Save to file**.

Uma cópia pronta do dashboard (a que o Grafana carrega sozinho) está em `grafana/dashboards/login-dashboard.json`.
